ELEMENTS — PART 1

Готовая статическая страница альбома. Для работы ей не нужны npm, сервер,
база данных или сторонние библиотеки.

Локальный просмотр:
откройте index.html в современном браузере.

Публикация на Cloudflare Pages:
1. Откройте Workers & Pages в панели Cloudflare.
2. Выберите Create application → Pages → Upload assets.
3. Перетащите всю папку site.
4. После загрузки сайт получит бесплатный адрес вида project.pages.dev.

Важно: загружать нужно содержимое папки site вместе с каталогом assets.
